# YM Presence

Показывает в Discord, что вы слушаете в Яндекс Музыке (Windows).

- Трек читается из системных медиа-данных Windows (SMTC), клиент Яндекс Музыки не изменяется.
- Тексты, ссылки, кнопки и обложка настраиваются в окне приложения.
- Обновления подтягиваются из GitHub Releases этого (приватного) репозитория.

## Разработка

```powershell
npm install
npm start          # запуск (из обычного PowerShell, не из терминала VS Code)
npm run dist       # установщик в release/
```

## Выпуск обновления

1. Поднимите `version` в `package.json` (например, 0.2.0).
2. Задайте токен с правом записи в репозиторий (Contents: Read and write):
   `$env:GH_TOKEN = "github_pat_..."`
3. `npm run release` собирает установщик и создаёт черновик релиза с `latest.yml`.
4. Откройте релиз на GitHub и нажмите Publish. Установленные приложения найдут его сами.

В приложении (вкладка «Приложение») нужен отдельный токен **только на чтение** (Contents: Read-only).
